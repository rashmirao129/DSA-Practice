
# Solve Me First

- **Platform:** HackerRank
- **Language:** Java
- **Difficulty:** Easy
- **Category:** Warm-up
- **Problem:** [Solve Me First](https://www.hackerrank.com/challenges/solve-me-first/problem)

## 1. Problem Goal

Given two integers, calculate their sum and return the result.

## 2. Approach

1. Read two integer values.
2. Pass both values to the `solveMeFirst()` method.
3. Add the two integers.
4. Return the sum.
5. Print the returned result.

## 3. Java Solution

```java
static int solveMeFirst(int a, int b) {
    return a + b;
}
```

## 4. Example

**Input:**
```text
2
3
```

**Output:**
```text
5
```

## 5. Explanation

- First integer: 2
- Second integer: 3
- Sum: 2 + 3 = 5

The method returns 5, which is printed by the main method.

## 6. Complexity Analysis

- **Time Complexity:** O(1)
- **Auxiliary Space:** O(1)
